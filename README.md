# 房贷计算器 · 微信小程序

买房贷款的各项数字，一次算清。原生微信小程序框架实现（无构建、无第三方依赖），界面采用 Apple Liquid Glass 毛玻璃风格。

等额本息 / 等额本金双视图，支持**组合贷款**（商贷 + 公积金）、**提前还款试算**（缩短期限 / 减少月供）、**利率浮动情景对比**、**还款明细按月展开**，结果可**导出为长图**（内容自选）。

## 功能特性

**贷款参数**
- 贷款金额以「万元」录入，配 ±1万 / ±10万 快捷步进
- 贷款利率：商贷预设（LPR 5 年以上 3.5%、5 年以内 3.0%、±20BP、+60BP）与公积金预设（2.6% / 2.1%），也可手动输入任意年利率
- 贷款年限 1–40 年，选项标注对应期数（如「30年（360期）」）
- 开始还贷月份选填，默认空；填写后自动推算已还期数并展示剩余还款情况

**还款方式**
- **等额本息**：月供、总利息、本息总计、贷款金额、贷款期限；填写开始月份后追加当前剩余还贷期数、剩余还贷总金额、剩余本金、剩余利息
- **等额本金**：首月月供、每月递减额（含末月）、总利息、本息总计、贷款金额、贷款年限
- 两种方式利息差额对比提示
- **组合贷款**：商贷 + 公积金两笔分别设置金额与利率，逐期合并计算，月供 / 利息 / 明细 / 剩余还款均为合并口径
- **还款明细**：按年分组折叠，每期展示期数、月供总额、本金、利息、剩余待还本金、剩余待还利息（避免一次性渲染 480 行）

**提前还款试算**（默认折叠）
- 输入提前还款金额与「第几期后还」，策略二选一：
  - **缩短期限**：月供不变，压缩剩余期数
  - **减少月供**：期限不变，降低月供
- 输出可节省利息、还款前后剩余本金、剩余期限或月供变化、新剩余利息
- 组合贷按各笔剩余本金占比分配还款额

**利率浮动对比**
- 在当前利率基础上 ±0.25% / ±0.5% 共五档，表格列出各档月供与总利息，当前档高亮
- 仅商贷部分随 LPR 浮动，公积金保持固定；纯公积金贷款时自动隐藏

**结果导出**
- 导出长图，内容自选：贷款参数 / 等额本息概览 / 等额本金概览 / 剩余还款情况 / 利率浮动对比 / 提前还款试算
- 明细可选范围：不导出 / 前 12 / 36 / 60 期 / 按年汇总
- canvas 2d 绘制，生成后可预览、保存到相册
- 超长内容（>7600px）提示减少勾选

**其他**
- 输入自动记忆（本地存储）
- 一键复制结果摘要

## 快速开始

1. 打开**微信开发者工具**，选择「小程序」→「导入项目」
2. 目录选择本仓库根目录（含 `app.json` 那一层）
3. AppID 点「测试号」由工具自动分配，或填入你自己的 AppID；后端服务选「不使用云服务」
4. 编译后进入计算页，填参数点【计算】跳转结果页

> `project.config.json` 中 `appid` 为空字符串，导入时走测试号流程即可。本项目为纯本地计算，不调用任何云服务与网络接口。

## 算法说明

**等额本息**月供：

```
月供 = 本金 × 月利率 × (1 + 月利率)^期数 / ((1 + 月利率)^期数 − 1)
```

**等额本金**：每月本金固定 = 本金 / 期数，月供 = 固定本金 + 剩余本金 × 月利率，每月递减额 = 固定本金 × 月利率。

**精度处理**（`utils/mortgage.js`）：
- 全程 `round2` 二分位舍入，模拟银行分期记账
- 末期对本金与利息做双向修正，使 360 期明细合计与「本息总计」精确闭合（差额 0.00）
- 零利率情景单独兜底，避免月利率为 0 时产生舍入「假利息」

**提前还款**：
- 缩短期限：解 `月供 = 新月供能力` 方程求新月数，`n = log(月供 / (月供 − 新本金 × 月利率)) / log(1 + 月利率)`
- 减少月供：期限不变重算月供
- 组合贷按各笔剩余本金占比分配提前还款额

## 数值校验

以 100 万 / 年利率 3.5% / 30 年（360 期）为例，与公开房贷计算器交叉核对一致：

| 指标 | 等额本息 | 等额本金 |
|---|---|---|
| 月供 / 首月月供 | 4,490.45 元 | 5,694.44 元 |
| 每月递减 | — | 8.10 元 |
| 总利息 | 616,560.88 元 | 526,458.33 元 |
| 本息总计 | 1,616,560.88 元 | 1,526,458.33 元 |

- 组合贷（商贷 60 万 @3.5% + 公积金 40 万 @2.6%，30 年）：合并月供 **4,295.63 元**，总利息 546,425.71 元；等额本金首月 5,394.45 元、每月递减 7.27 元
- 提前还款 10 万（第 36 期后，等额本息）：缩短期限省息 **133,502.28 元**，324 → 272 期；减少月供省息 54,718.87 元，月供 4,490.45 → 4,012.92 元
- 第 36 期已还后：剩余本金 940,354.05 元、剩余利息 514,550.63 元

算法层另经单元测试覆盖：合并计划明细合计与「本息总计」闭合、末期本金归零、超额还款自动截断、零利率兜底。

## 设计与交互

- **Liquid Glass 材质**：按 Apple HIG 配方分层——控件层 `rgba(255,255,255,.72) + blur(20px) saturate(180%)`，内容卡片 `0.62 + blur(26px) saturate(180%)`，卡片内部用标准填充 `rgba(118,118,128,.12)` 不再叠加第二层材质；1px 亮顶边模拟玻璃边缘光弯折
- 背景为 7 个高饱和彩色光斑 + 斜向高光条 + 颗粒层，给玻璃提供可折射的内容，光斑带缓慢漂移动画
- 自定义导航栏高度由胶囊按钮实测换算（`navMetrics()`），保证标题与右上角胶囊严格同线
- 点击目标 ≥ 44×44，`:active` 缩放反馈；支持 `prefers-reduced-motion` / `prefers-reduced-transparency` 降级
- 图标全部为内嵌 SVG 线性图标，无 Emoji
